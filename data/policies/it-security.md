# IT Acceptable Use and Security Policy

## Passwords and MFA

Use a password manager. Passwords must be at least 14 characters and unique to each system. Multi-factor authentication is mandatory for email, VPN and every system holding customer data.
Never share your password or MFA codes, including with IT staff. IT will never ask for them.

## Reporting incidents

Report suspected phishing, lost devices or any security incident to the Security Team immediately at security@acme.example or through an IT ticket with priority "critical".
A lost or stolen laptop must be reported within 1 hour of noticing, so the device can be locked and wiped remotely.

## Software

Install software only from the company software portal. Software not in the portal needs an IT ticket with the "software" category and approval from IT Security, which takes up to 5 working days.
Browser extensions that read page content need the same approval.

## AI tools

Use only company-approved AI tools for work. Do not paste customer data, source code or confidential documents into unapproved AI services.

## Access requests

Request access to systems with an IT ticket in the "access" category. Your manager must approve access to any system holding customer or financial data.
